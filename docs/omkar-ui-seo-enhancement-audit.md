# Omkar UI, UX, SEO, And GEO Enhancement Audit

Date: 2026-05-31

## Component Library Decisions

The site now uses focused component libraries that fit the existing React + Tailwind + shadcn-style system:

- Radix Accordion: used for the healing approach section and FAQ, because it is accessible, keyboard-friendly, and animation-ready.
- Embla Carousel: used for client stories, because it gives desktop and mobile visitors a swipeable, engaging story surface without turning the page into a heavy slider template.
- Motion for React: used for scroll progress, scroll-triggered reveals, and restrained transitions already aligned with the current codebase.
- shadcn-style local primitives: Button, Card, Input, Checkbox, Dialog, Progress, RadioGroup, and Accordion remain locally styled so the site keeps a calm wellness identity instead of becoming generic Material UI.

Primary docs checked:

- Radix Accordion: https://www.radix-ui.com/primitives/docs/components/accordion
- Embla React: https://www.embla-carousel.com/get-started/react/
- Motion scroll animations: https://motion.dev/docs/react-scroll-animations
- Google structured data intro: https://developers.google.com/search/docs/appearance/structured-data/intro-structured-data
